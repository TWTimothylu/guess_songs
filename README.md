# 🎬 好萊塢配樂猜猜看

聽一段好萊塢電影配樂，從四個選項中猜出是哪一部電影。音樂來源為 YouTube（IFrame Player API）。

## 玩法

- **難度**：簡單（15 秒，接近開頭）／普通（10 秒，隨機段落）／困難（5 秒，隨機段落）
- **題數**：5、10、20 題
- **題庫**：全部、純配樂、主題曲（共 48 首）
- 計分：答對 100 分 + 速度加分（最多 100）+ 連擊加分；各難度最高分存在瀏覽器中
- 快捷鍵：`1`–`4` 作答、`R` 再聽一次、`Enter` 下一題
- 作答後掀開封面播放原影片，結算畫面附每首曲目的 YouTube 連結

## 本機執行

YouTube 嵌入播放需要透過 http 開啟（直接開 `file://` 可能無法播放）：

```powershell
python -m http.server 8000
```

然後開啟 <http://localhost:8000>。也可以直接部署到 GitHub Pages（Settings → Pages → 選擇 `main` 分支）。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構（開始／遊戲／結算三個畫面） |
| `style.css` | 電影院風格樣式，支援手機版 |
| `game.js` | 遊戲邏輯與 YouTube 播放控制 |
| `songs.js` | 題庫：中英文片名、曲名、作曲者、年份、YouTube 影片 ID |

## 新增題目

在 `songs.js` 的 `SONGS` 陣列加一筆：

```js
{"zh":"中文片名","en":"English Title","track":"曲名","composer":"作曲者","year":2000,"type":"score","youtubeId":"影片ID"}
```

`type` 為 `score`（配樂）或 `song`（主題曲）。影片必須允許嵌入播放；若某支影片之後被下架或禁止嵌入，遊戲會自動跳過換下一首。
